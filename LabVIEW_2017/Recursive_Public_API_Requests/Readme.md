### Recursive Public API Requests

This example project demonstrates how to create recursive Public API Requests in a Worker base class that automatically propagate throughout an entire application's Worker call-chain hierarchy, enabling broadcast commands across all Workers in an application.


### What You'll Learn:

- Creating Public Requests in a Worker base class that cascade through multiple hierarchy levels
- Broadcasting commands to all Workers in a branch or the entire application
    

**Recommended for developers building applications requiring application-wide messaging.**
