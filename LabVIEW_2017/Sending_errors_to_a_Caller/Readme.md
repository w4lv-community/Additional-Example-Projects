### Sending Errors up the Worker call-chain

This example project demonstrates three different methods for sending errors from a Worker's MHL or EHL up the Worker call-chain to its Caller or any Worker above it for centralized processing.


### What You'll Learn:

- Method 1: Sending errors using Public API Responses (simple, decoupled)
- Method 2: Using the framework's "Send Error to Owner" VI (no base class required)
- Method 3: Using recursive Public API Requests in a base class (application-wide propagation)
  

**Ideal for applications requiring centralized error handling or collection.**
